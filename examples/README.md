# Examples

| Example             | Description                                                                                                                               |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `react-vite`        | Vite + React. Shows multiple different uses of useExternalState.                                                                          |
| `next-query-params` | Next.js App Router. Uses `@1apostoli/use-external-state-next` to bind multiple query parameters (search, category, price range, toggles). |

Each project depends on the workspace versions of `@1apostoli/use-external-state` (and the `/next` adapter when applicable), so edits to the libraries are reflected immediately when running the demos. The `predev`/`prebuild` scripts call the monorepo build to keep local bundles up to date.
